# Email Analyzer API

Сервис анализирует текст письма клиента и извлекает структурированные данные:

- имя клиента;
- компанию;
- суть обращения;
- признак недовольства.

Используется локальная модель через Ollama.

## Технологии

- Python 3.11
- FastAPI
- Pydantic
- Ollama
- Llama 3.1 8B
